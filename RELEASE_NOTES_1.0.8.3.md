# Editorial Masthead Profiles 1.0.8.3

This maintenance release makes the complete editorial-team view more concise.

## Changed

- Individual biographies are no longer loaded or displayed in the complete Editorial Masthead card view.
- Names remain linked to the journal-scoped public profile pages, where each member's public biography continues to be displayed.
- Profile images, affiliations, websites, verified ORCID links, service dates, and current role grouping remain unchanged on the masthead.

## Upgrade note

Upgrade installations running `1.0.8.2` to `1.0.8.3` and clear the OJS template and data caches.

## Compatibility

Primary target: OJS 3.5.0-5. The plugin does not modify OJS or theme templates on disk.
